## Updating to {{ product_name }} Controller `v0.36.0`

### Logging directives no longer merge with the built-in defaults

Logging directives are now taken from a single source, by priority:
`RUST_LOG` > `[logging].default_directives` > built-in defaults. Previously these
were merged, with the built-in defaults always applied as a base.

The `[logging]` section is otherwise unchanged. Action is only needed if you set
`default_directives` or `RUST_LOG` and rely on the built-in defaults still
applying — add the ones you want to keep explicitly. The built-in defaults are:

```toml
[logging]
default_directives = [
    "error",
    "opentalk=info",
    "pinky_swear=off",
    "rustls=warn",
    "mio=error",
    "lapin=warn",
    "execution_id=trace",
]
```

If you set neither `default_directives` nor `RUST_LOG`, no action is needed.
