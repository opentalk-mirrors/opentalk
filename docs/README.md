# OpenTalk Compose Administration Guide

OpenTalk Compose provides tools and utilities for deploying the OpenTalk video conferencing solution on your own server. Begin with the [Quickstart Guide](1-quickstart-installation.md), which walks you through the installation steps required to set up all necessary services for your OpenTalk instance. This guide assumes a standard scenario: a publicly accessible server where all components run on a single host, and SSL/TLS certificates are obtained via Let's Encrypt.

For customized setups or special requirements, refer to the [Advanced Installation Scenarios](4-advanced-installation-scenarios.md) in this documentation to explore configuration options that meet your needs. The Quickstart Guide covers the essential steps for a common installation.
