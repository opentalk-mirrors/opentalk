# Updating to {{ product_name }} Controller `v3.0.0`

## Spacedeck whiteboard implementation has been replaced with Excalidraw

The Spacedeck based `whiteboard` module has been replaced with the `excalidraw` module that was added as an
experimental module in `v0.34.0` of the controller.

The spacedeck container is obsolete and should no longer
be deployed. The backend for the excalidraw module is implemented in the roomserver and does not require any
external dependecies.

The `excalidraw` module in the configuration file has been renamed to `whiteboard` and replaces the old
configuration. The `base_url` and `api_key` configuration options are no longer required and have been removed.

Previous:

```toml
# Legacy spacedeck based whiteboard module
#[roomserver.modules.whiteboard]
base_url = "http://localhost:9666"
api_key = "secret"
```

New:

```toml
# New excalidraw based whiteboard module
[whiteboard]
```
